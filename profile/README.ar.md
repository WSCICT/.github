# الواحة السحرية | Al‑Wahha Al‑Sehriya

[English](https://github.com/WSCICT/.github/blob/main/profile/README.md) · [العربية](https://github.com/WSCICT/.github/blob/main/profile/README.ar.md) · [Türkçe](https://github.com/WSCICT/.github/blob/main/profile/README.tr.md) · [Русский](https://github.com/WSCICT/.github/blob/main/profile/README.ru.md) · [Deutsch](https://github.com/WSCICT/.github/blob/main/profile/README.de.md)

**تصميم وتطوير المواقع • الاستضافة والصيانة • تطوير الـBackend • تحليل البيانات • تطوير التطبيقات**

بخبرة تمتد لنحو 15 عاماً، تساعد **الواحة السحرية** الشركات والمؤسسات على تحويل أفكارها إلى حلول رقمية عملية. نجمع بين تطوير المواقع والتطبيقات، وأنظمة الأعمال، والاستضافة وتحليل البيانات لتعزيز حضورك الرقمي وتسهيل أعمالك اليومية.

## خدماتنا

- **تصميم وتطوير المواقع:** مواقع الشركات، المواقع المتجاوبة، بوابات المؤسسات، صفحات الهبوط ولوحات التحكم.
- **الاستضافة والصيانة:** استضافة المواقع، VPS، السيرفرات المخصصة، بريد الأعمال، SSL، النسخ الاحتياطي والمراقبة والدعم الفني.
- **أنظمة الأعمال:** حلول مخصصة لإدارة المشاريع والعقود والفواتير والوثائق والعمليات.
- **الذكاء الاصطناعي والأتمتة:** مساعدون أذكياء، البحث في المعرفة، تنظيم البيانات وأتمتة الإجراءات.
- **الأمن والحماية:** إدارة الصلاحيات، تقوية الأمان وحماية المواقع.
- **الهوية والحضور الرقمي:** تنظيم المحتوى وعرض هوية الشركة بشكل احترافي.
- **تطوير تطبيقات Android وiOS:** تطبيقات مصممة لاحتياجات أعمالك، تربط عملاءك وفريقك بخدماتك بسهولة.
- **تطوير الـBackend:** خدمات Java وSpring Boot، واجهات REST APIs، المايكروسيرفس، المصادقة والصلاحيات حسب الدور، والربط مع قواعد بيانات PostgreSQL وMySQL.
- **تكامل الأنظمة والأتمتة:** الرسائل باستخدام Kafka، تجهيز ونشر الخدمات باستخدام Docker، وسير عمل مدعوم بالذكاء الاصطناعي باستخدام Spring AI.
- **تحليل البيانات وذكاء الأعمال:** تجهيز البيانات وتحليلها، لوحات معلومات تفاعلية، متابعة مؤشرات الأداء وتقارير الإدارة باستخدام **Power BI وTableau**.

## مجالات حلول الـBackend

- **أنظمة البنوك:** إدارة الحسابات والمعاملات، الوصول الآمن وتكامل الأنظمة.
- **أنظمة إدارة العيادات:** ملفات المرضى، المواعيد وصلاحيات الموظفين.
- **أنظمة التجارة الإلكترونية:** كتالوج المنتجات، الطلبات، المخزون والربط مع خدمات الدفع.

نصمّم هذه الحلول بما يتناسب مع إجراءات عملك، واحتياجات التكامل وأولويات مؤسستك.

## منتجاتنا وحلولنا

### Offeria — منصة طلبات التسعير والعروض

منصة مصممة لتنظيم طلبات التسعير ومعرفة المواد والعروض الفنية والتجارية ضمن سير عمل موحّد للمشتريات.

[تعرّف على Offeria](https://github.com/offeria-io)

### WSEMS — نظام إدارة المؤسسات

اجمع إدارة المشاريع والعقود والفواتير والمالية والوثائق والموارد البشرية والأصول والمشتريات والتقارير في منصة واحدة. يمنح **WSEMS** فريقك رؤية أوضح لأعمال المؤسسة، مع وحدات وصلاحيات وإجراءات عمل قابلة للتخصيص حسب احتياجاتك.

### نظام إدارة المجلات العلمية

حل للمجلات الجامعية والعلمية، بواجهة عربية وإنكليزية، وأرشيف للأعداد والمجلدات، وبحث، ومعلومات هيئة التحرير وأدلة المؤلفين والمحكمين وسياسات النشر، مع الاستضافة والصيانة.

[تفاصيل نظام المجلات](https://wahasehriya.com/journal-management-system)
